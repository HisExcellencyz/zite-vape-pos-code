# zite-vape-pos-code
Create a customizable POS and inventory tracking system for a vape-selling business with the following features:
* the landing page invites users to Authenticate before accessing the app.
* default currency set to Kenya Shillings (KES), ability to add other currencies.
* accessible on multiple devices, by multiple users, via the internet.
* ability to create users with different credentials and permissions.
* calculation of stock value, profit and loss, and inclusion of expenses.
* recording of deposits made to suppliers, and calculation of balances.
* ability to set up product images, categories and variations if need be.
* inputs for all tabs can also be done via Excel/CSV and Sheets uploads.
* have an entry for customers too, such that a customer's name and contact can be added to a POS at any time.
* all tabs' data should be downloadable to Excel/CSV, Slides and PDF where possible. 
* can record when we pay deposits to suppliers, such that it deducts when we pick stock from them.
* includes Purchases, which can then deduct from deposits to suppliers.
* in the supplier's Transaction button, make it possible to actually choose a product.
* allows for editing of the business name and other entity details, as well as upload a logo, and maybe even a cover photo.
* assigns all non-admin users to the main branch by default, unless otherwise assigned.
* can show results for each branch, as well as for the whole business.
* has a list of permissions, eg. who can edit, write or view information on all tabs.
* non-admin users should not be able to edit transactions already completed, so only the admin can. 
* share all such possible permission, such that the rolegates are granular.
* can allow for creation of user groups where users who need similar permissions will fall under.
* allows for linking and creating customers for POS sales, and suppliers for purchases to record payment from deposits or cash.
* assumes the purchase was paid in cash, hence records it under expenses, unless it is linked to a supplier with a deposit.
* allows for customizable report viewing and downloads to Excel, Word, PDF and PowerPoint, wherever each applies.
* offers different theme templates to choose from, or allows for total customization to match business desired colors.
* makes it all entirely cloud based so that no data is ever lost.
* during poor connectivity periods, allow for both auto and manual sync after connection restores.
* settings includes a button where I can add new entity details, like Tax IDs, Address etc.
* taxes and commissions can be set up there then tagged/attached to sales.
* one can filter for Custom periods and dates, not just the predetermined ones.
* taxes and commissions attached to sales are recorded as Expenses, like Purchases.
* it breaks down all expense types by the category created, in visual graphs and pie charts.
* dashboard shows in-depth reports on performances per product, customer and supplier.
* the phone number is the primary ID key for customers. It should include a + sign and numbers.
* customer name is a mandatory requirement but not necessarily a primary key.
* a drill-down of each customer shows the number of orders made, and total value.
* one can enter expenses that are not tied to products, but MUST give a description.
* one can record multiple products and their quantities in one Expense creation.
* the two expense types are split into either Purchases or Other Expenses options.
* each supplier can be tagged to all the products they supply us to avoid confusion.
* each branch includes a button where I can add new entity details, like Tax IDs, Address etc.
* each product in inventory can be tagged to all the suppliers that can supply it to us.
* product name, SKU, cost price and selling price are all mandatory fields to add products.
* products with cost price or selling price of zero are set as inactive by default, unless admin activates.
* taxes can be set up per product, or in bulk but not mandatory.
* inventory includes a bulk actions tab to edit availability, stock and prices.
* where a product SKU exists and appears in an import file, it edits the existing.
* an SKU cannot exist in duplicate even when other details like product name differ.
* POS tab includes a button where one can record an Other Income, that isn't purely a sale.
* taxes and commissions are included in the already listed prices, not added to them.
* dashboard includes a period filter, so that it displays data for selected Custom periods.
* it also displays the top selling products in the period filtered, and customers with most orders.
* invited users can be prompted to verify, create credentials and get accesses assigned to them.
* the creator (me) is automatically assigned to the Admin group, which has maximum access.
* invitations can be visible on the users tab, with status changing from Unverified to Verified.
* arrange the buttons such that the one to manually Add is far-right, then the Import, and finally the Export.
* the logo should show on the profile icon above the Dashboard tab.
* introduce an option to download templates whenever one needs to import entities.
* let the templates be downloadable from the dialog boxes that pop up from the Import buttons.
* let the download templates icons have a yellowish theme.
* make the entire app theme feature a creative blend of pink, yellow, blue and green.
